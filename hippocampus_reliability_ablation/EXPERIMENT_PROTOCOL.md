# Ablation protocol

Primary question: does pair-aligned reliability improve results beyond simply reducing
planning update sizes?

Compare fixed Dyna-Q, reliability-weighted Dyna-Q, unweighted planning with the same
model/reliability pipeline, and shuffled reliability scores. Report greedy evaluation
success, training success, final-window steps, mean planning reliability, and per-maze
and per-seed results. Keep results separate from all prior implementations.
